
原本為何使用 wp？
- 足夠彈性，但用了多年其實發現用到的功能不多，更不需要複雜的商城功能（這是很多人使用的原因）


核心需求：
- 自主資料管理：可雲端下載 MySQL 或自己 host
- Markdown 編輯器：內建 Koenig
- 靜態生成網站：可以掛 Cloudflare
- 會員＋訂閱：只需要填 Stripe Key

附帶需求：
- 快：遠勝 Wordpress
- 安全：動態生成部分少（可以控制只暴露會員 endpoint），不需要連基本會員登入功能都安裝外掛，增加安全風險




# 下一個十年的創作平台

## Substack 開始大眾化

不只是部落格，去年開始也發現 Substack 在中文圈越來越流行，讓我想到之前在 Medium、Matters、方格子等平台的熱鬧景象。

願意寫作的人變多是好，但同時具有投資、職涯、心靈雞湯、AI 生成屬性的文章開始變多，有些作者甚至同時包含了好幾個屬性，讓我有種既視感。

這裡先不談論誰寫的比較低俗、誰比較高尚，但從客觀的受眾群體來說，以上屬性的文字創作更面向大眾讀者，而我的文章顯然很小眾。而一但平台變得如此大眾化，我就會想要逃走。

過去的經驗告訴我，寫作平台在大眾化之後不知為何的，就一定會走樣，可能是投資者要出場把平台變現、或者其他大人的原因，但總之，別人的平台嘛，總有一天我是一定要走的。

之前常說推特、臉書這些社群，總有一天要準備好被砍帳號，這倒不是說希望大家從現在開始別用。反而我覺得拼命享受平台的資源，但同時擁有一個完全由自己掌握的窟、不受制於平台，才是最好的。（怎麼有點像是工作？）

所以只要平台社群屬性跟我的文章屬性開始漸行漸遠，或者覺得 Substack 也有點越來越像脆，我就覺得是時候可以想一下自己的「窟」是否需要更新一下。


「創作者的自主性」是一個悖論：大家都知道很重要，但真正實踐的沒有幾個，或許我在推廣的時候不應該以利益得失作為賣點，而是以信仰或樂趣作為訴求：「有一個自己的部落格，當別人被平台搞的時候就是爽啦！」
